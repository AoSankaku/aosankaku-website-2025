## 【くらふたーず▲】について

【くらふたーず▲】は、「なんか作ってる人」が集まっている場所です。こんなことが好きな人達に来てほしいな、と思っています。

- 個人開発（自己サイト、プログラム等）
  - 個人開発を応援している人も歓迎します
- 自作ゲーム（同人ゲーム）
  - 同人ゲームを遊ぶのが好きな人も歓迎します
- 工作（電子じゃないものも含む）
- イラスト・3Dモデル・デザイン
- 配信・動画投稿
- 料理・インテリア・リフォーム等
- MinecraftやCities Skylinesなど自由度の高いゲーム愛好者

また、以下のような活動も広義で「なんか作ってる人」とみなし歓迎します。

- サーバーを運用している人
- 1からモノづくりはしていないが、他者プロジェクトにプライベートで貢献している人
- 個人（事業）で活動をしている人
- 事情や年齢によりまだ手を出していないが、なにか作りたいとずっと思っている人

## ローカルルール

※ローカルルールは、利用規約を構成します（利用規約第二条第五項）。

（目的）

1. Misskeyにはローカルタイムライン（以下、「LTL」という。）機能があります。運営者は、その裁量によりLTLを監督および管理し、どのようなLTLを構築するのか管理する権限を持っています。
2. 運営者は、LTLがこのような空間であることを望んでいます。
	1. 精神的に成熟した人間同士が、関係性に応じて適切な距離感を保ちつつ交流できる。
	2. 過大または不適当な要求ではない場合において、他者のNG話題や行為を尊重できる。
	3. ローカルルールを尊重する限り、新しいLTL会話の参加者を暖かく迎え入れることができる。
	4. 連合をONにする場合、各ユーザーが他の連合先サーバーと衝突などが起きないような内容を吟味して投稿することができる。

（してほしくないこと）

3. 第2項に掲げるようなLTLを実現するために、以下は望ましくありません。
 	1. 身内ネタ（個人を指定し、ちょっかいをかける行為）→HTLでやるのが望ましい。
	1. 政治、宗教、スポーツ、学歴、理系文系→当サーバーは、「作ったもの」を共有したりそれを軸に交流するサーバーです。それ以外の話題で、特に議論を巻き起こしそうなものはチャンネルに隔離してください。
	2. 本人が求めている以上に高額または高度な商品を繰り返し紹介する行為
	3. 当サーバーのAIポリシーに違反する行為
	4. 過大な話題のNGを出す行為
4. 新規LTL会話参加者に対して、以下のような行為は望ましくありません。
	1. 不適切なリアクションの付与
	2. 距離感を考えない関わり方

（適用範囲）

5. 各チャンネルにおいて、原則として第3項および第4項の忌避事項は準用します。

（管理）

6. 管理者は、ローカルルールに違反するユーザーに対して罰則を適用することがあります。
7. 管理者は、LTLを第2項に掲げるような空間に維持するために、特定の単語を禁止したり直接的に現在進行中の話題の中断を指示することがあります。

## 生成AIポリシー

当サーバーは、生成AIについて概ね肯定的に受け入れますが、できるだけ多くの人に快適に当サーバーをご利用いただけるように、その利用について一部制限を課します。

1. 生成AIについて、立場にかかわらず他者に思想を強要することを禁止します。
2. 「AIスロップ」の投稿を禁止します。AIスロップとは、生成AIが大部分またはすべてを作成したものであり、かつ以下の要件を複数満たすものをいいますが、管理者が総合的に判断します。
   1. 会話やコミュニティの文脈等を踏まえていないこと
   2. 単純なプロンプト等により産出されたものであること
   3. 成果物の品質が低く、「マスピ顔」などAI生成である特徴が全面的に出ている作品であること
   4. 誤った情報や特徴を多くまたは重要な部分に含んでいること
   5. AIを使った試作品であることを明記しておらず、かつCWを付していないこと
   6. 他者に悪意を持ってAI生成ではないと誤認させるような形態であること
   7. 短期間に多数の作品を投稿すること
   8. 思想および感情を表現したものではないために、著作権法の保護対象とならない可能性が高いこと
3. 生成AIを使用して直接的に作成したものについては、AIスロップの要件に当てはまらないものであってもCWを付し、その旨を明記することを推奨します。生成AIを補助的に利用したり、またはその生成物の大部分を加工したものや生成過程において大量の独自プロンプトを入力した場合等で、著作権法の保護対象となる要件を十分に満たす可能性がある作品等にはCWを付す必要はありません。
4. 試作品である場合や、AIを試してみただけの作品等の場合はCWを付すことを推奨します。
5. AIスロップではない作品等を公開する場合であっても、文化庁等が示すように他者の著作物に依拠して著作物を作成した場合は著作権を侵害する可能性が十分にあることを理解し、自己の責任において投稿を行ってください。
